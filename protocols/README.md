# Protocols and their chronology

Every protocol in this folder was committed to the repository before the work it governs. This page makes that checkable in one click per step. Each time below is the commit's timestamp, in UTC, linked to the commit itself. Every commit listed was made on GitHub's own servers, not on a local machine: commits by `ricd-tracker-bot` were made by the GitHub Actions workflows that ran each step, each with its own run log in the Actions tab, and the others are uploads through GitHub's web interface, which GitHub timestamps itself. Each commit's page shows its committer: `GitHub` for a web upload, `ricd-tracker-bot` for a workflow; of the commits linked here, 52 are the first and 30 the second, and none was made elsewhere. The order of the commits is also fixed by the history, since each commit records the one before it.
