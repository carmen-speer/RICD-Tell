# Future Projects

This folder holds work that is proposed, seeded, or theorized but not yet
built, funded, or validated — kept visible here rather than folded into the
validated tracker above, so the real state of each idea is checkable rather
than asserted.

## Contents

- [`Next Project for RICD - Four Adapter Build Roadmap.pdf`](<Next Project for RICD - Four Adapter Build Roadmap.pdf>) —
  a proposed build plan for four new RICD tracker adapters —
  banking, hospitals, public schools, and nursing homes/long-term care —
  chosen for having both large public datasets and realistic commercial
  application.
- [`RICD Ongoing Projects Roadmap.docx`](<RICD Ongoing Projects Roadmap.docx>) —
  the broader roadmap of further RICD-based trackers planned beyond the
  four adapters above and the higher-ed tracker in this repository.
- [`Collapse-Causal Agent Tracker (C-CAT) Seed Note.pdf`](<Collapse-Causal Agent Tracker (C-CAT) Seed Note.pdf>) —
  a seed note for a genuinely different kind of tracker: an agent tracker,
  investigating the specific real decisions and agents behind a collapse
  (board minutes, depositions, investigative findings) rather than the
  aggregate financial and enrollment effects the higher-ed tracker
  measures. The higher-ed tracker measures the direct causes of collapse
  (stress and resource debt); this planned tracker would look one level
  further upstream, at the agents whose decisions produced those causes.
- [`Anchor-Quantification Sensor - Seed Note.md`](<Anchor-Quantification Sensor - Seed Note.md>) —
  a proposed quantification of anchor-eligibility (external support
  capable of preventing collapse without appearing in the classifier's
  own math), to run alongside the validated 8-feature panel and
  cross-reference against it rather than merge into it. Tests directly
  against Sweet Briar and Phoenix-Arizona, the two live cases already
  documented in Known Gaps.

Two related projects that draw on RICD but are not part of Tell live in
their own repositories:
[Plurimo](https://github.com/carmen-speer/RICD-Plurimo) and the
[Web–Field Model of Cognitive Trait Distributions and Social Evolution](https://github.com/carmen-speer/RICD-Web-Field-Model-Systems-Cognition).
