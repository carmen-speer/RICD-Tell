# Future Projects

This folder holds work that is proposed, seeded or theorized but not yet
built, kept visible here rather than folded into the tested tracker, so
the real state of each idea is checkable rather than asserted.

## Next domains (decided November 2026)

Each is planned as its own dedicated, named repository, as Tell is, and
written up as a comparison with Tell, so the theory can be tested where
anchoring is weaker than in higher education. Neither is built yet.

- **Fisheries, first:** the first non-human domain. Prediction: the size
  and growth of the gap between assessed and later-revised stock size
  predicts collapse better than stock level, read from the RAM Legacy
  Stock Assessment Database, with historical baselines from before modern
  assessments.
- **Nonprofits, second (or hospitals in their place):** nonprofits read
  through their federal tax filings (IRS Form 990), across a few
  subsectors that run from heavily to thinly anchored, so the anchoring
  interaction can be tested inside one data source. If the filings or
  their outcomes prove too hard to read, hospitals replace them (closure
  lists and Medicare cost reports).
- **Normalized drift:** the collapse of the northern cod set against
  Sweet Briar's rescue, testing whether slow decline ends in collapse more
  often because it is normalized, yet is easier to reverse before the
  point of no return (RICD 17.8, §10.5a); then the World3 model read as
  RICD containers, to ask how late an anchor can start and still reverse
  the decline.

## Contents

- [`RICD Ongoing Projects Roadmap.docx`](<RICD Ongoing Projects Roadmap.docx>) —
  the broader roadmap of further RICD-based trackers planned beyond the
  higher-ed tracker in this repository.
- [`Collapse-Causal Agent Tracker (C-CAT) Seed Note.pdf`](<Collapse-Causal Agent Tracker (C-CAT) Seed Note.pdf>) —
  a seed note for a genuinely different kind of tracker: an agent tracker,
  investigating the specific real decisions and agents behind a collapse
  (board minutes, depositions, investigative findings) rather than the
  aggregate financial and enrollment effects the higher-ed tracker
  measures. The higher-ed tracker measures the direct causes of collapse
  (stress and resource debt); this planned tracker would look one level
  further upstream, at the agents whose decisions produced those causes.
- [`Next Project for RICD - Four Adapter Build Roadmap.pdf`](<Next Project for RICD - Four Adapter Build Roadmap.pdf>) —
  the earlier build plan for four adapters (banking, hospitals, public
  schools, and nursing homes/long-term care), kept as a record; the next
  domains above replaced it.

record in
